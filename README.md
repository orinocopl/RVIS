
# Database for RVIS (Ravio-Visual Imaging System)

Database files and scripts for data acquisition and processing:


rvisdata - SDR 4 channel recordings

record.m - MATLAB script for launching acquisition

r2 - Bash script for controlling the UR-4 device and the noise generator

RFIDFixedReaderUR4.java - Java application for controlling the UR-4 RFID interrogator

backscatter.m - MATLAB script for processing RFID backscatter signals

cameraframe.jpg - reference image from the PS3Eye camera

nuand2getsync.grc - GRC configuration for Nuand BladeRF SDR devices

nuand2sync.py - GRC script for controlling Nuand BladeRF SDR devices
